# Amazon Clone

## Description
This project is a front-end clone of the Amazon homepage developed using HTML and CSS. It replicates the basic layout and design of Amazon, including the navigation bar, search bar, hero section, product categories, and footer.

## Technologies Used
- HTML5
- CSS3
- Font Awesome Icons

## Features
- Amazon-style navigation bar
- Search bar with category selection
- Hero banner section
- Product category cards
- Responsive layout using Flexbox
- Footer with multiple information sections
